# Digest — access terms, feasibility and fallback (round 1)

Access date: 2026-11-23.

- No documented public case-search API or redistribution permission was found for Georgia or Nebraska.
- Georgia: account-only court/vendor routing; GSCCCA prohibits automation/compiling; PeachCourt prohibits data collection avoiding billing; no statewide public search. Live automation = **not approved**.
- Nebraska: statewide paid access; one-time terms prohibit redistribution; subscriber agreement is end-user/non-transferable; bulk/index contracted; no public API. Live automation = **not approved** for MVP.
- Approved fallback: functional fictional search + guided official manual lookup, persistent fictional/live labels, explicit selection not identity verification.
- Cost units documented: GA GSCCCA $14.95/$29.95 monthly, $0.50/page; PeachCourt $2/document + $0.50/page + 3.5% + $0.30; NE $17 one-time, $100/year + $2/case, $1,000–$2,000/month bulk/index.
- Legal sources need version/effective-date tracking and qualified legal review; EEOC 2012 guidance status disputed; FCRA currency gap; Georgia code volumes partial.

Decision proposal: adopt fallback for E6; defer live court integration to a separately scoped owner decision; proceed to E1-S1 authentication next; no paid access or accounts.
