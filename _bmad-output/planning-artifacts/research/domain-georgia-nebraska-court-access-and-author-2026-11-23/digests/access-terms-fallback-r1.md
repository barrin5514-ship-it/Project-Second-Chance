# Digest — access terms, feasibility and fallback (round 1)

Access date: 2026-11-23.

- No documented public case-search API or redistribution permission was established for Georgia or Nebraska.
- Georgia: E-Access is account-gated court-by-court vendor routing; no single statewide public search established in this review. Reviewed GSCCCA/PeachCourt terms are source-specific (automation/compiling; billing avoidance) and do not speak for every Georgia vendor/county site. Live automation = **not feasible on current evidence**.
- Nebraska: statewide paid access; one-time terms prohibit redistribution; subscriber agreement's non-transferable licence expressly concerns provided software, and affirmative display/redistribution permission for subscriber/bulk data was not established; bulk/index contracted; no public API. Live automation = **not authorized on current evidence** for MVP.
- Approved fallback: **both** functional fictional candidate search and guided official manual lookup, persistent fictional/live labels, explicit confirmation/selection not identity verification.
- Cost units documented: GA GSCCCA $14.95/$29.95 monthly, $5 single-use, $0.50/page; PeachCourt $2/document + $0.50/page + 3.5% + $0.30 (document states 2022-04-13 update); NE $17 one-time, $100/year + $2/case, $1,000–$2,000/month bulk/index; $2 excess above 20,000.
- Legal sources need version/effective-date tracking and qualified legal review; the 2012 EEOC guidance is rescinded per the 2026-10-29 official announcement, while the separate Q&A/2014 guidance need current-status review; FCRA currency gap; Georgia code volumes partial.

Decision proposal: adopt fallback for E6; defer live court integration to a separately scoped owner decision; proceed to E1-S1 authentication next; no paid access or accounts.
